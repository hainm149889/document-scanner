# rn-document-scanner

High-performance document camera scanner for CCCD (Vietnamese ID) and Passport supporting React Native New Architecture and Nitro Modules.

## Features
- Native Camera Preview (AVFoundation / Camera2)
- Custom Overlays & Framing
- High-res Image Capture
- CCCD & Passport Parsers

## Installation
```bash
npm install rn-document-scanner react-native-nitro-modules
